## 개요

알고리즘 문제의 **제약 조건(Constraints)**은 단순한 입력 설명이 아니라 사용할 수 있는 알고리즘의 시간 복잡도, 자료형, 메모리 구조를 알려 주는 단서이다.

구현부터 시작하기 전에 입력의 최댓값을 복잡도에 대입해 보면 완전 탐색이 가능한지, 정렬이나 이분 탐색이 필요한지, 전처리를 해야 하는지를 빠르게 판단할 수 있다.

## 입력 크기와 시간 복잡도

일반적인 1 ~ 2초 제한에서 참고할 수 있는 대략적인 기준이다.

| 입력 크기 `n` | 고려할 수 있는 복잡도 | 대표적인 방법 |
|----|----|----|
| `n <= 10` | `O(n!)` | 순열 완전 탐색, 백트래킹 |
| `n <= 20` | `O(2^n)` | 부분 집합, 비트마스크 DP |
| `n <= 100` | `O(n^3)` | 플로이드-워셜, 3중 반복문 |
| `n <= 1,000` | `O(n^2)` | 모든 쌍 비교, 2차원 DP |
| `n <= 100,000` | `O(n log n)` | 정렬, 우선순위 큐, 분할 정복 |
| `n <= 1,000,000` | `O(n)` | 한 번의 순회, 누적합, 투 포인터 |
| 매우 큰 `n` | `O(log n)`, `O(1)` | 이분 탐색, 수학적 계산 |

이 표는 절대적인 기준이 아니다. 같은 복잡도라도 상수 시간, 언어, 하드웨어, 입출력의 양에 따라 실행 시간은 달라진다.

예를 들어 `n = 100,000`일 때 `O(n^2)`은 약 `10^10`번의 연산이 필요하므로 현실적으로 어렵지만, `O(n log n)`은 대략 수백만 번의 연산으로 처리할 수 있다.

## 여러 제약을 함께 보기

입력값이 하나가 아니라면 각 값이 실제 반복 횟수에 어떻게 관여하는지 확인해야 한다.

- 테스트 케이스가 `T`개이고 매번 `O(n)`이라면 전체 복잡도는 `O(Tn)`이다.
- 정점이 `V`개, 간선이 `E`개인 그래프 탐색은 인접 리스트 기준으로 `O(V + E)`이다.
- 쿼리가 `Q`개이고 각 쿼리가 `O(log n)`이라면 전처리를 제외한 비용은 `O(Q log n)`이다.
- `n`과 `m`의 크기 차이가 크다면 무조건 `O(nm)`을 피하기보다 실제 최댓값의 곱을 먼저 계산한다.

## 자료형의 범위

정답뿐 아니라 **중간 계산 결과**도 자료형의 범위를 넘을 수 있다.

| C# 자료형 | 범위 | 크기 |
|----|----|----|
| `int` | 약 `-2.1 * 10^9` ~ `2.1 * 10^9` | 4 byte |
| `long` | 약 `-9.2 * 10^18` ~ `9.2 * 10^18` | 8 byte |

예를 들어 `n <= 100,000`이고 모든 쌍의 개수 `n(n - 1) / 2`를 구한다면 결과는 `int`의 범위를 넘는다.

```cs
int n = 100_000;

// 곱셈 전에 long으로 변환해야 중간 결과도 long으로 계산된다.
long pairCount = (long)n * (n - 1) / 2;
```

`long pairCount = n * (n - 1) / 2;`처럼 작성하면 `int`끼리의 곱셈에서 먼저 오버플로가 발생한 다음 `long`에 저장되므로 올바른 결과를 얻을 수 없다.

## 메모리 제한

시간 복잡도가 충분해도 자료구조가 메모리 제한을 넘을 수 있다.

- `int` 원소 `1,000,000`개는 데이터만 약 4 MB를 사용한다.
- `int[10_000, 10_000]`은 데이터만 약 400 MB이므로 대부분의 문제에서 부담이 크다.
- 인접 행렬은 `O(V^2)`, 인접 리스트는 `O(V + E)`의 공간을 사용한다.
- 재귀 호출은 호출 스택을 사용하므로 입력의 깊이가 크면 반복문과 명시적인 스택을 고려한다.
- 객체나 중첩 컬렉션은 실제 데이터 외에도 관리 비용이 추가된다.

## 확인 순서

1. 모든 입력값과 테스트 케이스 수의 최댓값을 확인한다.
2. 생각한 알고리즘의 반복 횟수에 최댓값을 직접 대입한다.
3. 정답과 중간 계산에 필요한 자료형을 정한다.
4. 배열, 그래프, DP 테이블의 대략적인 메모리를 계산한다.
5. 최악의 입력에서도 시간과 메모리 제한을 만족하는지 확인한다.
